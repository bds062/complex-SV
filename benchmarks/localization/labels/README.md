# Label tables

These four files are the exact labels used to train and evaluate the selected 108-label model:

- `BFB.tsv`: 42 events
- `chromothripsis.tsv`: 36 events
- `ecDNA.tsv`: 13 events
- `seismic_amplification.tsv`: 17 events

`all_labels.tsv` is their combined source table. The later 42-call chromothripsis revision was evaluated separately and was not adopted because retraining reduced held-out F1.
