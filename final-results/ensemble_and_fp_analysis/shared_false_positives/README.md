# Shared false-positive localization gallery

Each image spans the complete chromosome and highlights only one localization-model interval. A shared false positive means that both models called the same sample/chromosome/class key and that key is false positive under the observed labels.

Images are ranked within class by the held-out localization score. When one shared key has multiple localized FP intervals, each estimate is rendered as a separate image.
